❓ Как пользоваться генератором

📌 Постановление

  • Заполните Основные данные — номер, судью, фракцию и т.д.
  • Добавляйте Действия к исполнению — нажмите ➕ Добавить действие
  • В действии выберите тип (Уведомление, Боди-Камера, Запрет, Отстранение)
  • Для Боди-Камеры укажите дату и интервал времени
  • Для Отстранения укажите руководство
  • Кликните по действию — оно развернётся для редактирования
  • Перетаскивайте действия мышкой, чтобы изменить их порядок

🎙️ Допрос

  • Заполните данные допроса — имя, паспорт, дату и содержание
  • Укажите время, место и присутствующих (опционально)

🔍 Розыск

  • Заполните Общую информацию — номер, судью, тип суда
  • Добавляйте Разыскиваемых — нажмите ➕ Добавить разыскиваемого
  • Укажите статьи обвинения — если их несколько через запятую, слово "статье" автоматически заменится на "статьям"
  • Выберите Вид заключения — УК СА или АК СА
  • Укажите Срок — он автоматически склоняется (год/года/лет)
  • Перетаскивайте разыскиваемых мышкой, чтобы изменить их порядок

📋 Итоговое

  • Проверьте статус заполнения всех разделов
  • Убедитесь, что все обязательные поля заполнены

⚙️ Настройки

  • В настройках укажите должность, имя и подпись
  • Ссылка на подпись автоматически подставится в шаблон

📋 Результат

  • Всё генерируется автоматически при изменении данных
  • Нажмите 📋 Копировать — скопируйте готовый BBCode
  • Нажмите ↺ Сбросить — очистите все поля
